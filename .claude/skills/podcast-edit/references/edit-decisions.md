# Edit decisions: what is SAID decides what the edit DOES

Every device needs a reason in the words. Read the transcript line, classify the beat, apply the device.
Derived from a second-by-second breakdown of ref ig2 (below) plus ig1/ig3/yt2.

## The beat -> device table
| Beat in the speech | Device | Engine |
|---|---|---|
| **Hook claim** (first line: bold claim, "you don't need...") | open tight on the speaker (1.1-1.2x), keyword lockup on the claim word within 1 s | `zoom`, `keywords` |
| **Big number / proof** ("100,000 followers") | switch to band layout, number HUGE (behind the head in B), whoosh | `layout: band` + keyword / HyperFrames text-behind |
| **Host asks the question** | cut to host (full or split), show both names the first time we see both | `layout: split` + `names` |
| **Goal / from-to numbers** ("0 to 10K in 3 months") | counter ticker 0 -> target | `counters` |
| **Listener reaction** (nod, laugh, crossed arms, "hmm") | cutaway to listener 0.5-1.5 s while the speaker's audio continues | segment from the listener cam, `nocaps` optional |
| **"Before / don't / mistake / most people"** | black-and-white (dim) for that sentence, back to colour on the fix | `look: bw` |
| **Contrarian / provocative question** ("What is your contrary view?") | typewriter or tight lockup, punch-in on the asker | `keywords`, `zoom` |
| **Speaker points at something visual** ("look at performing ideas in your niche") | B-roll insert: phone mockup / screen recording / photo (2-4 s) | HyperFrames insert or a `card` |
| **Abstract concept** ("you'll see a pattern") | graph line / diagram behind the speaker | HyperFrames (registry chart) |
| **Key term in a list** ("script", "framework") | glowing stamp on the term | `stamps` |
| **Counting / specific numeral** ("N number of", "first 3 seconds") | the numeral alone, HUGE; tick 2 -> 3 if it's a count | `keywords` (the number), counter for ticks |
| **Contrast pair** ("visually, verbally") | side-by-side or split, one word per side, B&W behind | `layout: split` + captions |
| **Enumerated list** ("topic, hook, format, CTA") | checklist stack, one item per spoken word | `stacks` timed to each word |
| **Payoff / punchline** | tightest punch-in of the clip (1.25-1.35x), hold 0.3 s, no overlay | `zoom` |
| **Topic change** | dip to black (2-4 frames) or wide two-shot, whoosh | short `card` with black `bg`, or the wide cam |
| **Unanswered follow-up** ("Which is the highest priority?" "I just said...") | end on it -> CTA card ("Comment LINK") | `endcard` |

## Zoom rules (when to punch in, and how far)
- Two framings per camera: **base** (1.0, chest up) and **tight** (1.2-1.3x, face + shoulders). Extreme (1.5x+) only on 4K, once per clip.
- Go tight on: the hook line, the keyword/number, the punchline, emotion (laugh, voice drops, leans in).
- Go back to base on: the next sentence, setup/explanation lines, any gesture with hands (don't crop the hands mid-gesture).
- On a single long answer, alternate base/tight on sentence ends every 3-6 s, so a static camera never holds > 6 s.
- Never zoom in the middle of a word; zoom changes are cuts (hard punch), not slow pushes, except the opening 0.5 s.

## Split-screen rules
- **Stacked split** (top/bottom): introductions (both names), fast Q->A ping-pong, a reaction to a bold claim.
  Hold 2-4 s, then go back to a single speaker. Speaker who's talking = bottom (bigger attention), unless the asker matters more.
- **Side-by-side split**: contrast pairs and "this vs that".
- **Band** (sharp 16:9 strip over a blurred copy): numbers/claims that get big text, and as a transition between full-frame shots.
- Never more than ~30% of a clip in split/band; full-frame faces carry emotion.

## Topic -> look
| Topic | Look |
|---|---|
| Wisdom, life lessons, relationships, motivation, karma, mindset | **A. letterbox lockup** |
| How-to, frameworks, growth numbers, business, money, fitness protocols | **B. creator hyper-edit** |
| Personal story, emotional confession, long careful answer | **C. clean minimal** (or A) |
| Funny moment, banter | C with fast reaction cutaways |
One clip = one look. Don't mix A's lockups with B's stacks.

## Clip shape (from ig2: two Q->A blocks in 54 s)
1. 0-3 s **Hook**: guest's strongest claim, tight.
2. 3-6 s **Proof**: the number that makes the claim credible.
3. 6-11 s **Question** from the host (names on, split, counter).
4. 11-35 s **Answer** in 3-5 beats, a device per beat (B&W "before", lockup, B-roll, graph, punch-in payoff).
5. Dip to black -> optional **second Q->A** with a list (stamps, numeral, stack).
6. **Open loop** -> CTA card.
